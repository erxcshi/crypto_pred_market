run from inside the crypto_pred_market repo root!!
(Windows: .venv\Scripts\activate | POSIX: source .venv/bin/activate)

COLLECTOR (the main thing — writes local parquet to data/):
DATA_SINK_MODE=parquet python -m data_gather.scrapers.run_all
  - or set DATA_SINK_MODE=parquet in .env (see .env.example)
  - 24/7 setup: deploy/windows_setup.md (NSSM) or deploy/*.service (Linux)

daily compaction (small files -> one per day, scheduled or manual):
python -m data_gather.compact

read collected data:
  import polars as pl
  pl.scan_parquet('data/<table>/**/*.parquet').collect()

single scrapers (debugging):
python -m data_gather.scrapers.polymarket_ws     # etc.

trading engine (paper mode — currently non-runnable: model/feature layer was
removed 2026-07-18 for the from-scratch rebuild, see CLAUDE.md):
python -m trading.engine --dry-run
